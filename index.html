    Layout & content

    3D model

    A .glb is one file, so pick it on its own. A .gltf keeps its geometry in a .bin and its textures as separate images, so select all of them together or use Folder.

    What each level shows

    Object names exactly as they appear in Blender.

    Size and place a whole object

    Scale multiplies whatever the model was exported at, so 1 is unchanged and 0.5 is half. Use it to shrink the ground plane, for instance. Move and turn are added on top.

    Ground

    The exported ground has no material, and the level 1 volume is exported as double sided glass. These two switches are what make level 1 read cleanly.

    Extra objects

    A plane starts lying flat, so it works as a bigger ground or, stood upright, as a wall behind the model.

    How it dissolves

    Crossfade keeps the two shapes adding up to fully opaque, so the building never thins out. Snap decides how fast it crosses over: low is a long blend of both shapes at once, high is a quicker swap. Starts and ends are fractions of the whole move.

    How the camera moves

    Runs the whole move from wherever you are, so you can judge it rather than imagine it.

    Sun

    Long low shadows come from a low sun.

    Shadows

    Softness comes from the edge together with the resolution and the area. How dark a shadow looks is Shadow fill below. Raise the surface offset if shadows stripe flat surfaces.

    Your working copy

    Everything you change lives only in this browser tab until you write it out. There are three ways to keep it, for three different jobs.

    Leave this on and a saved HTML file carries the model inside it, so it runs from any folder.

    1. Editable HTML

    The file you are working in, with every change baked in and the panel still present. This is the copy to keep and come back to.

    2. Viewer HTML, to publish

    The finished module with the panel stripped out, about half the size. It carries every change but cannot be edited in the browser, so keep copy 1 or a settings file too.

    3. Settings file

    A small .dprset.json with every change but not the model. Use it to keep versions side by side and load any of them back into a fresh copy of the editable file.

    If a download is blocked

    Some LMS frames block downloads. Paste it over the block between CONFIG START and CONFIG END.

    Editable keeps the panel. Viewer is the one to publish. The Save tab explains both and holds the settings file.

    Your settings

    Open the HTML in a text editor, find CONFIG START and CONFIG END near the top, and replace everything between them with this.
